# Панель ценников (HTML + JavaScript, один файл)

`index.html` — готовая панель для печати прайс-листа по шаблону. Цены и фото
подтягиваются из YML-файла (формат Яндекс.Маркета) по ссылке. Ни сборки, ни
сервера, ни установки: файл открывается двойным кликом в любом браузере.

## Как пользоваться

1. Скачайте `index.html` и откройте его в браузере (Chrome, Edge, Firefox, Safari).
2. Вкладка **Каталог** → вставьте ссылку на YML → **Загрузить**.
   Если сайт не отдаёт CORS-заголовки, браузер заблокирует прямой запрос — выберите
   прокси в списке ниже, либо скачайте `.yml` и загрузите его как файл, либо вставьте
   XML текстом.
3. Найдите товар в поиске (по названию, артикулу или id):
   * клик по карточке — добавить позицией в список;
   * кнопка **★** — сделать основным товаром (большое фото сверху).
4. Кнопки **+ позиция** и **+ раздел** на листе добавляют пустую строку или заголовок
   раздела. Любой текст на листе правится прямо на месте (клик и печатайте).
5. Вкладка **Лист** — половина листа, размеры шрифта, полей, миниатюр и валюта.
6. **🖨 Печать / PDF** — системный диалог печати. В настройках печати выберите
   «Поля: нет» и масштаб 100 %, чтобы размеры совпали до миллиметра.

## Что умеет

* **YML по ссылке** — разбор `<offer>`: название (или `typePrefix + vendor + model`),
  `price`, `oldprice`, `currencyId`, `picture`, `vendorCode`, `categoryId` с
  подстановкой имени категории, флаг `available`.
* **Фото-миниатюра у каждой позиции** — берётся из `<picture>` оффера; можно
  заменить своим файлом (клик по миниатюре). Свои изображения сжимаются до 520 px
  JPEG, чтобы влезали в localStorage. Битая ссылка на фото заменяется заглушкой «ФОТО».
* **Только одна половина A4** — вторая половина листа помечена и остаётся пустой:
  * A4 альбомная — левая или правая половина (148,5 × 210 мм);
  * A4 книжная — верхняя или нижняя половина (210 × 148,5 мм).
  При печати задаётся `@page size: A4 landscape|portrait; margin: 0`, лист выходит
  в натуральную величину.
* **Контроль переполнения** — если содержимое перестаёт помещаться в половину листа,
  панель обводится красным и появляется предупреждение (при печати лишнее обрезалось бы).
* **Обновление цен** — кнопка «Обновить цены из YML» перечитывает прайс и
  подставляет актуальные цены по сохранённому id оффера; сообщает, сколько позиций
  изменилось и сколько не нашлось.
* **Разделы, примечания, перетаскивание** позиций мышью, стрелки ↑/↓, удаление.
* **Шаблоны** — сохранение листов в браузере, экспорт/импорт в JSON-файл.
  Текущий лист сохраняется автоматически и восстанавливается при открытии.

## Форматы и ограничения

* Ожидается стандартный YML: `yml_catalog → shop → offers → offer`. Нестандартные
  поля игнорируются, товар всё равно попадёт в каталог.
* Валюта берётся из `currencyId` (RUB, KZT, USD, EUR, UAH, BYN…), символ можно
  задать вручную на вкладке «Лист».
* Фото из YML печатаются по ссылке — на момент печати нужен интернет. Чтобы
  печатать офлайн, подставьте изображения со своего компьютера.
* Цену можно перебить руками прямо на листе — она останется, пока не нажата кнопка
  обновления цен.
