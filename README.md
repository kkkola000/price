# Панель ценников (HTML + JavaScript, один файл)

`index.html` — готовая панель для печати прайс-листа по шаблону. Цены и фото
подтягиваются из YML-файла (формат Яндекс.Маркета) по ссылке. Ни сборки, ни
сервера, ни установки: файл открывается двойным кликом в любом браузере.

## Как пользоваться

1. Скачайте `index.html` и откройте его в браузере (Chrome, Edge, Firefox, Safari).
2. Вкладка **Каталог** → вставьте ссылку на YML → **Загрузить**.
   Панель сама пробует загрузить файл напрямую, а если сайт не разрешает
   (CORS) — через публичные ретрансляторы, и пишет, какой способ сработал.
   Если закрыты все, сохраните файл по ссылке (Ctrl+S) и загрузите его кнопкой
   «Выберите файл» — этот путь работает всегда. Можно и просто вставить XML текстом.
3. Найдите товар в поиске (по названию, артикулу или id):
   * клик по карточке — добавить позицией в конец списка;
   * кнопка **★** — поставить первым. Фото первой позиции печатается крупно вверху
     половины листа — отдельного «основного товара» заполнять не нужно.
4. Наведите курсор на строку — сбоку от листа появится панель кнопок:
   **⠿** перетащить, **↑ ↓** переместить, **🖼** заменить фото, **≡** примечание,
   **✕** удалить. Строку можно и просто перетащить мышью (кроме текста).
5. Кнопки **+ позиция** и **+ раздел** на листе добавляют пустую строку или заголовок
   раздела. Любой текст правится прямо на месте (клик и печатайте).
6. Вкладка **Лист** — раскладка листа, размеры шрифта, полей, миниатюр и валюта.
7. **🖨 Печать / PDF** — системный диалог печати. В настройках печати выберите
   «Поля: нет» и масштаб 100 %, чтобы размеры совпали до миллиметра.

## Что умеет

* **YML по ссылке** — разбор `<offer>`: название (или `typePrefix + vendor + model`),
  `price`, `oldprice`, `currencyId`, `picture`, `vendorCode`, `categoryId` с
  подстановкой имени категории, флаг `available`. Понимаются и товарные RSS-фиды
  (`<item>` с `g:price`, `g:image_link` и т. п.).
* **Загрузка устойчива к типовым помехам**: кодировка берётся из XML-декларации
  (UTF-8, windows-1251), `.gz` распаковывается на лету, HTML-страница вместо
  прайса и пустой ответ распознаются с понятным сообщением, а при блокировке CORS
  перебираются ретрансляторы.
* **Фото-миниатюра у каждой позиции** — берётся из `<picture>` оффера; можно
  заменить своим файлом (клик по миниатюре). Свои изображения сжимаются до 520 px
  JPEG, чтобы влезали в localStorage. Битая ссылка на фото заменяется заглушкой «ФОТО».
* **Большое фото** вверху половины — это фото первой позиции списка. Поменяли порядок —
  поменялось и фото.
* **Три раскладки листа** (вкладка «Лист» → «Как используется лист»):
  * **Один прайс с перетеканием** (по умолчанию) — товары заполняют первую половину,
    а когда она кончается, автоматически продолжаются во второй;
  * **Две независимые половины** — два разных прайса на одном A4, у каждого своё
    большое фото и свой список;
  * **Только одна половина** — вторая остаётся пустой (левая/правая или верхняя/нижняя).
  Над каждой половиной (только на экране, в печать не идёт) есть переключатель
  «заполняется эта половина» — им выбирают, куда попадают товары из каталога.
  Если включить его на второй половине в режиме перетекания, лист сам перейдёт
  в режим двух независимых прайсов.
  Ориентация листа — альбомная (половины слева и справа) или книжная (сверху и снизу);
  при печати задаётся `@page size: A4 landscape|portrait; margin: 0`, лист выходит
  в натуральную величину.
* **Контроль переполнения** — если товары не помещаются даже на обе половины,
  переполненная половина обводится красным и появляется предупреждение
  (при печати нижние строки обрезались бы).
* **Обновление цен** — кнопка «Обновить цены из YML» перечитывает прайс и
  подставляет актуальные цены по сохранённому id оффера; сообщает, сколько позиций
  изменилось и сколько не нашлось.
* **Разделы, примечания, перетаскивание** позиций мышью (в том числе между половинами),
  стрелки ↑/↓, удаление.
* **Список товаров не переживает перезагрузку** — панель всегда открывается
  с чистым листом. Между сеансами запоминаются только настройки: раскладка,
  размеры, валюта, ссылка на прайс.
* **Шаблоны** — чтобы вернуться к прайсу позже, сохраните его шаблоном
  (вкладка «Шаблоны») или выгрузите в JSON-файл; оттуда лист восстанавливается
  целиком, вместе с загруженными фотографиями.

## Форматы и ограничения

* Ожидается стандартный YML: `yml_catalog → shop → offers → offer` (либо RSS с
  `<item>`). Нестандартные поля игнорируются, товар всё равно попадёт в каталог.
* **Почему ссылка открывается в браузере, но не грузится в панели.** Открытие
  страницы и запрос из JavaScript — разные вещи: во втором случае браузер требует
  от сервера заголовок `Access-Control-Allow-Origin`. Если вы управляете сайтом,
  добавьте его к отдаче прайса — тогда ссылка будет работать напрямую.
* Валюта берётся из `currencyId` (RUB, KZT, USD, EUR, UAH, BYN…), символ можно
  задать вручную на вкладке «Лист».
* Фото из YML печатаются по ссылке — на момент печати нужен интернет. Чтобы
  печатать офлайн, подставьте изображения со своего компьютера.
* Цену можно перебить руками прямо на листе — она останется, пока не нажата кнопка
  обновления цен.
